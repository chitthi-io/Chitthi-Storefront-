## 4. NOTES FOR THE STUDIO

- All six builds are **sample orders** (Anya & Prateek demo data). A real order
  replaces `CLIENT_CONFIG` at the top of each keepsake's `<script>` — names,
  dates, captions, letters, quiz answers, prize text, RSVP message, envelopes.
- `voiceNote` is `null` in every build; the player UI is wired and appears
  automatically once a real voice clip path is dropped into `CLIENT_CONFIG`.
- Audio: two self-hosted CC0 tracks matched by mood (romantic/ceremonial →
  track A; playful/celebratory → track B). No external audio URLs — ever.
- Every keepsake is `noindex,nofollow`; photos used are the studio's existing
  demo set (airport / chai / goa / goodbye), to be swapped for customer photos
  on real orders.
